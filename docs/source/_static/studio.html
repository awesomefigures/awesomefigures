1. Palette

Choose a famous palette to preserve its exact published RGB coordinates, or use the custom WCAG/OKLCH generator. Named historical palettes do not guarantee a particular adjacent WCAG ratio. Start with systematic hue spacing; fine-tune each hue below. OKLCH hue angles are evenly spaced, not guaranteed perceptually distinct. The luminance ladder supplies additional contrast.

Hue/luminance matrix

Rows are luminance levels; columns are your current hue choices. Click a cell to assign that column's hue to the row.

2. Hue order and plot identifiers

Move rows to change which hue receives each luminance level. Marker and linestyle are redundant identifiers for grayscale/monochrome output.

Line-style and marker atlas

Every style is drawn as it appears on the plot. Use the per-series picker above to assign any dash pattern.
