# AwesomeFigures agent instructions

## Repository-first delivery

GitHub is the source of truth. Work on feature branches, commit and push all
meaningful source, tests, documentation, notes, generated verification reports
and CI evidence. Do not leave essential results only on ephemeral VMs or in
chat. Never commit secrets, TeX auxiliary files, caches, environments, or
private manuscripts.

## Publication subsystem

- Preserve the existing `inspect_latex`, `latex_style`,
  `PublicationStyle.fit/audit/savefig`, and PGF APIs.
- The high-level `paper` context lives in
  `src/awesomefigures/auto_publication.py` and orchestrates those lower
  layers; avoid implementing a second independent layout probe.
- The .tex input must be a **trusted preamble**. Never execute arbitrary
  paper builds or shell escape from figure rendering.
- Do not call statistical experiments, optimizers, data downloads or
  model-fitting functions from publication code. The caller supplies
  an already-created Matplotlib Figure.
- Only a PDF generated by the manuscript's real TeX preamble and validated
  with PDF font resources may claim exact font provenance. Ordinary PNG/SVG
  and Matplotlib PDF exports are previews.
- PDF sizes must be verified in physical PostScript points and converted
  to TeX points appropriately: 72 PDF points vs 72.27 TeX points/inch.
- Optional PDF-auditing dependencies go in the `publication` extra;
  ordinary plotting should not import them eagerly.
- Tests must cover cached inspection, width resolution, font embedding,
  PDF dimensions, export failures and legacy API compatibility. The TeX CI
  workflow exercises a real pdflatex/PDF path separately.
- Avoid committing output from full statistical runs to this library repo.
  Use fixed deterministic data for technical publication examples.

## Handoff

Consult `AI_HANDOFF/publication_automation.md` and the new Sphinx guide.
Before declaring the task complete, run pytest, strict Sphinx and the real
LaTeX integration workflow, then link evidence in the PR. Never merge the
upstream PR without explicit user approval.
